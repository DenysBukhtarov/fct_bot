# FCT Assistant Bot — інструкція запуску

Бот для Telegram-групи спортивного залу: меню, розклад, ціни, запис, привітання нових учасників і базовий антиспам.

## Що всередині

- `bot.py` — код бота
- `config.py` — усі тексти й налаштування (редагуйте тут, без знання Python)
- `.env.example` — шаблон для токена
- `requirements.txt` — залежності

## Крок 1. Створіть бота через BotFather

1. Відкрийте в Telegram **@BotFather**, натисніть **Start**.
2. Введіть команду `/newbot`.
3. Придумайте назву (наприклад `FCT Assistant`).
4. Придумайте username — обов'язково закінчується на `bot` (наприклад `FCT_Tornado_bot`).
5. BotFather видасть рядок вигляду:
   `123456789:AAxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
   — це ваш **токен**. Нікому його не показуйте і не публікуйте.

## Крок 2. Встановіть Python-залежності

Потрібен встановлений Python 3.10+.

```bash
pip install -r requirements.txt
```

## Крок 3. Вставте токен

1. Скопіюйте файл `.env.example` і перейменуйте копію на `.env`.
2. Відкрийте `.env` і вставте токен після знаку `=`:
   ```
   BOT_TOKEN=123456789:AAxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```

## Крок 4. Відредагуйте тексти під свій зал

Відкрийте `config.py` і замініть:
- розклад тренувань (`SCHEDULE_TEXT`)
- ціни (`PRICES_TEXT`)
- адресу (`ADDRESS_TEXT`)
- контакти, сайт, Instagram
- свій Telegram user_id у `ADMIN_IDS` (щоб дізнатись id — напишіть **@userinfobot**)

## Крок 5. Запустіть бота

```bash
python bot.py
```

Якщо все правильно — у консолі з'явиться "Бот запущено."

## Крок 6. Додайте бота у групу

1. Відкрийте свою групу в Telegram → **Учасники** → **Додати**.
2. Знайдіть бота за username, який ви створили в BotFather.
3. Зробіть його **адміністратором** з правами:
   - видалення повідомлень (для антиспаму)
   - блокування учасників (для попереджень/бану)

## Що вміє бот

**Для клієнтів (в особистих повідомленнях з ботом):**
- 📝 **Записатися** — напрямок → група → день → ім'я → телефон. Заявка приходить адміну з кнопками «Підтвердити / Відхилити», клієнт отримує відповідь. Напередодні тренування бот нагадує.
- 🆓 **Пробне заняття** — те саме + коротка анкета (вік, досвід, мета).
- 🧾 **Реквізити** + ✅ **Я оплатив** — клієнт надсилає квитанцію, адмін обирає тип оплати (абонемент / разове / персональне), бот веде облік абонементів.
- 🎫 **Мій абонемент** — до якої дати діє абонемент, найближчі записи з кнопкою «Скасувати».
- 🎂 /birthday — день народження (бот привітає в групі).
- Нагадування: за 3 дні до кінця абонемента і коли він закінчився.

**Для адміністратора** (`/admin` в особистих повідомленнях):

| Команда | Що робить |
|---|---|
| `/admin` | список команд + посилання для cron-job.org |
| `/bookings` | записи на 7 днів |
| `/subs` | чинні абонементи |
| `/debtors` | абонементи, що закінчились і не продовжені |
| `/stats` | статистика (у групі — кількість учасників) |
| `/broadcast` | розсилка всім, хто писав боту |
| `/set` | змінити тексти (розклад, ціни, реквізити…) прямо в боті |
| `/birthdays` | найближчі дні народження |

Щопонеділка бот надсилає адміну тижневий звіт і список боржників.

**У групі:** `/poll` — опитування «Хто буде на тренуванні», `/warn` `/unwarn` `/warns` — попередження (відповіддю на повідомлення), антиспам посилань, привітання новачків.

## Налаштування на Render (Environment)

| Змінна | Обов'язково | Що це |
|---|---|---|
| `BOT_TOKEN` | так | токен від @BotFather |
| `DATABASE_URL` | для запису/оплат | рядок підключення Supabase (Session pooler) |
| `ADMIN_IDS` | так, для заявок | ваш Telegram ID (команда `/myid`), кілька — через кому |
| `CRON_SECRET` | ні | ключ для адреси нагадувань; якщо не задано — генерується з токена |

Нагадування надсилаються, поки бот не спить. Щоб вони йшли вчасно, додайте в **cron-job.org** задачу раз на годину на адресу з команди `/admin`.

Напрямки, групи, типи абонементів, години нагадувань — у `config.py` (розділи «ЗАПИС ЧЕРЕЗ БОТА», «АБОНЕМЕНТИ / ОПЛАТИ»).

## Важливо про хостинг

Поки на вашому комп'ютері запущений `python bot.py` — бот працює. Якщо закрити термінал/комп'ютер, бот вимкнеться.

Щоб бот працював 24/7, розмістіть його на сервері (наприклад VPS) або на безкоштовних платформах для довготривалих процесів (Railway, Render та подібні — умови й ціни перевіряйте самостійно, вони змінюються).

## Збереження попереджень

Якщо на Render задано змінну `DATABASE_URL` (Postgres, наприклад безкоштовний Supabase),
попередження зберігаються в базі й не скидаються після перезапуску або «сну» бота.
Таблиця `fct_warnings` створюється автоматично. Без `DATABASE_URL` попередження зберігаються в пам'яті.
