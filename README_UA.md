# FCT Assistant Bot — інструкція запуску

Бот для Telegram-групи спортивного залу: меню, розклад, ціни, запис, привітання нових учасників і базовий антиспам.

## Що всередині

- `bot.py` — код бота
- `config.py` — усі тексти й налаштування (редагуйте тут, без знання Python)
- `.env.example` — шаблон для токена
- `requirements.txt` — залежності

## Крок 1. Створіть бота через BotFather

1. Відкрийте в Telegram **@BotFather**, натисніть **Start**.
2. Введіть команду `/newbot`.
3. Придумайте назву (наприклад `FCT Assistant`).
4. Придумайте username — обов'язково закінчується на `bot` (наприклад `FCT_Tornado_bot`).
5. BotFather видасть рядок вигляду:
   `123456789:AAxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
   — це ваш **токен**. Нікому його не показуйте і не публікуйте.

## Крок 2. Встановіть Python-залежності

Потрібен встановлений Python 3.10+.

```bash
pip install -r requirements.txt
```

## Крок 3. Вставте токен

1. Скопіюйте файл `.env.example` і перейменуйте копію на `.env`.
2. Відкрийте `.env` і вставте токен після знаку `=`:
   ```
   BOT_TOKEN=123456789:AAxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```

## Крок 4. Відредагуйте тексти під свій зал

Відкрийте `config.py` і замініть:
- розклад тренувань (`SCHEDULE_TEXT`)
- ціни (`PRICES_TEXT`)
- адресу (`ADDRESS_TEXT`)
- контакти, сайт, Instagram
- свій Telegram user_id у `ADMIN_IDS` (щоб дізнатись id — напишіть **@userinfobot**)

## Крок 5. Запустіть бота

```bash
python bot.py
```

Якщо все правильно — у консолі з'явиться "Бот запущено."

## Крок 6. Додайте бота у групу

1. Відкрийте свою групу в Telegram → **Учасники** → **Додати**.
2. Знайдіть бота за username, який ви створили в BotFather.
3. Зробіть його **адміністратором** з правами:
   - видалення повідомлень (для антиспаму)
   - блокування учасників (для попереджень/бану)

## Команди бота

| Команда | Хто може | Що робить |
|---|---|---|
| `/start` | всі | відкриває меню |
| `/menu` | всі | показує меню повторно |
| `/rules` | всі | показує правила |
| `/warn` (у відповідь на повідомлення) | адміни | попередження учаснику |
| `/unwarn` (у відповідь на повідомлення) | адміни | знімає попередження |
| `/stats` | адміни | кількість учасників групи |

## Важливо про хостинг

Поки на вашому комп'ютері запущений `python bot.py` — бот працює. Якщо закрити термінал/комп'ютер, бот вимкнеться.

Щоб бот працював 24/7, розмістіть його на сервері (наприклад VPS) або на безкоштовних платформах для довготривалих процесів (Railway, Render та подібні — умови й ціни перевіряйте самостійно, вони змінюються).

## Обмеження антиспаму в поточній версії

Попередження зберігаються в пам'яті процесу — якщо бот перезапуститься, лічильники попереджень скинуться. Для production-варіанту з постійним збереженням даних (файл чи база даних) — дайте знати, і я додам це окремо.
